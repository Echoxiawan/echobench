# 安全与已知限制

## 安全边界

- 服务只监听 `127.0.0.1:4710`，没有登录鉴权，不要反向代理或暴露到公网。
- Appium 默认也没有认证；Server URL + Session ID 等同于设备控制权。
- YAML、界面和三种导出脚本都会明文显示/保存输入值，不要直接录制真实密码、令牌或个人敏感信息。`secret: true` 只会跳过输入文本校验，不会隐藏或加密内容。
- 草稿缓存在当前浏览器的 localStorage 中，不会上传；共用电脑时请用“清空”或清理浏览器数据删除。
- AI 配置只保存在当前浏览器；测试和导出时配置会临时转发给本地服务调用用户指定的 AI 接口，请求结束后不保留。
- 运行日志可能包含 Appium 输出、页面 source、设备信息和错误堆栈；提交 Issue 前请脱敏。

漏洞披露方式见 [SECURITY.md](../SECURITY.md)。

## 已知限制

- 单设备工作区一次维护一个 Appium 会话；多端同步支持多个并发会话。附加会话默认不结束外部会话。
- 元素树当前覆盖原生控件树；WebView context、HTML 元素检查和跨 context 操作尚未实现。
- 尚无独立的 headless CLI runner、JUnit/HTML 报告、失败视频归档和 CI 插件；回放目前主要在工作台中发起。
- 多端同步使用相对坐标广播，不是帧级同步；运行中动态增删设备和 iOS 自动重连尚未实现。
- 系统权限弹窗、通知栏、复杂多指手势和复杂键盘行为尚未形成统一 DSL；当前只提供标准双击、长按和双指缩放。
- 候选降级优先使用唯一安全候选，其次使用唯一序号候选兜底；类名、父容器和 bounds 不参与自动降级。每次命中都会实时确认仅 1 个元素；如果页面变化导致所有候选都失效，仍会按策略失败或使用坐标兜底。
- Android 自绘界面或默认窗口未带出的控件可能只能使用相对坐标；本工具已开启多窗口抓取，坐标回放仍可能受布局变化影响。需要稳定定位器时请让开发补充 contentDescription 或 resource-id。
- iOS 流畅度受 WDA 截图机制限制，通常低于 Android H.264；iOS 手势和候选定位器仍以真机实测为准。
- 项目不是云设备农场，不提供大规模并发、设备矩阵或企业级测试管理。
- 项目使用 Apache-2.0；第三方依赖仍受各自许可证约束，分发时需保留相应声明。
