# 多端同步

点击顶部“多端同步”，选择一台或多台在线设备开始。任意一台设备都可以作为操作入口，操作会广播给所有参与同步的设备，让它们一起执行。它与录制工作区是独立功能：只操作，不录制、不生成步骤或断言，也没有时间线/检查器。

## 行为

- 每台设备显示：在线/离线/连接中/异常、分辨率、前台 App、实时状态和最近操作结果。
- **实时** 开关只控制视频；**同步** 开关决定是否接收广播操作，两者互相独立。
- 支持全部实时 / 全部关闭、全部同步 / 全部暂停；实时画面不互斥，可以全部开启。
- 点击任意设备画面即把操作广播给所有参与同步且在线的设备；拖动发送滑动。
- 底部支持返回、文本输入、退格、回车和删除；非实时设备可手动刷新截图。
- 启动多端同步会释放当前单设备会话，避免同一设备或 WDA 端口冲突。

## 平台与风险

- Android 通过 ADB 操作，视频使用每设备独立 scrcpy 流；iOS 通过每设备独立 Appium/XCUITest 会话和 MJPEG 端口。
- iOS 模拟器只有真正启动后才会显示在线；`xctrace` 会列出所有已创建模拟器，未启动的会显示“未启动”且不可选。可执行 `xcrun simctl boot <UDID>` 或从 Xcode 启动。
- Windows 不支持 iOS，iOS 设备不可选；macOS 可混合 Android + iOS。
- 混合平台使用相对坐标广播，但不同系统的布局、状态栏、输入法和返回行为可能不同，可能落到不同控件。开始前会要求确认，运行中持续显示警告。
- Android 的 ADB 文本输入不支持直接输入中文等非 ASCII 内容，这类设备会单独报错；其他设备继续执行。
- 多端模式 Android 默认 960 长边 / 15 FPS / 2 Mbps，iOS 使用较低 MJPEG 画质。全部实时仍会显著增加 CPU；超过 2 路会提示。
- 单次最多 8 台设备；iOS 多设备首连需要为每台设备构建 WDA，耗时明显长于 Android。
- 多端同步使用相对坐标广播，不是帧级同步；运行中动态增删设备和 iOS 自动重连尚未实现。

## 适用场景

- 同一操作在多台 Android/iOS 设备上复现；
- 对比不同尺寸、系统版本或输入法下的页面反应；
- 在不生成正式录制步骤的情况下做快速手工回归。

需要可回放的流程时，请回到单设备工作区录制或载入 YAML，多端同步不会保存步骤。
