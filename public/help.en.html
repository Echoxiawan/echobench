Installation & connection help

EchoBench installers bundle Electron, Node.js, Appium, ADB, scrcpy-server, and the CI-built JRE. Most connection failures come from Android SDK, USB drivers, device authorization, JDK, or Xcode configuration.

中文
Recommended order

Start device → authorize USB debugging → confirm adb devices -l shows device → verify Android SDK → verify JDK → verify Appium drivers → click Connect in EchoBench.

Identify the missing layer

Bundled

Usually already included

  • Electron and Node.js runtime
  • Appium and UiAutomator2/XCUITest drivers
  • Android Platform-Tools and adb
  • scrcpy-server
  • CI-built JRE
May need setup

Common missing items

  • Windows: Android SDK, Google USB Driver, device authorization
  • macOS: Android SDK, full Xcode, iOS signing
  • Linux: Android SDK, udev rules, plugdev permissions

Windows: Android

RequiredAndroid SDK

Install Android Studio and SDK

  1. Install Android Studio.
  2. Install Platform-Tools, Build-Tools, Emulator, and an Android Platform in SDK Manager.
  3. The default SDK path is usually %LOCALAPPDATA%\Android\Sdk.
  4. Set both Android environment variables and restart EchoBench.
setx ANDROID_HOME "%LOCALAPPDATA%\Android\Sdk" setx ANDROID_SDK_ROOT "%LOCALAPPDATA%\Android\Sdk"
Physical device

Install the USB driver

For Google devices, install Google USB Driver from SDK Tools. For other brands, install the manufacturer driver.

Official driver guide

JDK / Java

winget install EclipseAdoptium.Temurin.17.JDK -e java -version
Bundled

ADB

EchoBench uses the bundled adb. Do not set a different ANDROID_ADB_SERVER_PORT unless you intentionally manage a separate server.

adb devices -l adb kill-server adb start-server

macOS: Android

Required

Install Android SDK

The default path is ~/Library/Android/sdk.

export ANDROID_HOME="$HOME/Library/Android/sdk" export ANDROID_SDK_ROOT="$ANDROID_HOME" export PATH="$ANDROID_HOME/platform-tools:$PATH"
Usually bundled

JDK

brew install openjdk@17 java -version

Linux: Android

Required

Install Android SDK

Install Android Studio or Command-line Tools. The default path is often ~/Android/Sdk.

export ANDROID_HOME="$HOME/Android/Sdk" export ANDROID_SDK_ROOT="$ANDROID_HOME" export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH" sdkmanager "platform-tools" "build-tools;35.0.0" "platforms;android-35"
Physical device

USB permissions

sudo usermod -aG plugdev "$USER" sudo udevadm control --reload-rules sudo udevadm trigger

Sign out and back in after changing group membership.

iOS: macOS only

Full Xcode

Install Xcode

Install Xcode from the App Store, launch it once, accept the license, then install command-line tools.

xcode-select --install sudo xcodebuild -license accept xcodebuild -version
Physical device

WebDriverAgent signing

Open node_modules/appium-webdriveragent/WebDriverAgent.xcodeproj and configure a Team and Bundle ID for WebDriverAgentRunner. Then enter the XCODE TEAM ID, signing identity, and WDA Bundle ID in EchoBench.

RemoteXPC tunnel for iOS 18+

Connect over USB and run:

sudo node node_modules/appium/index.js driver run xcuitest tunnel-creation

Developer Mode and trust

Enable Developer Mode on the iPhone, trust this computer, and confirm the device in Xcode Devices and Simulators.

Device setup

Android device

  • Enable Developer options.
  • Enable USB debugging and USB installation.
  • Unlock the device and allow the USB debugging prompt.
  • Prefer File Transfer / MTP USB mode.

Android emulator

  • Start the emulator before EchoBench.
  • Confirm adb devices -l lists it as device.
  • Run adb reconnect offline if it is offline.
  • Do not point EchoBench at a different ADB server port.

Common errors

device unauthorized

Unlock the device, reconnect USB, and tap Allow in the USB debugging prompt. Revoke and reauthorize if needed.

device offline

Run adb reconnect offline and reconnect the device. Cold-boot the emulator if necessary.

Android SDK not found

Install Android SDK, set ANDROID_HOME and ANDROID_SDK_ROOT, then fully restart EchoBench.

Java not found

Install JDK 17, set JAVA_HOME, and add its bin directory to PATH.

no permissions (Linux)

Configure Android udev rules, add the user to plugdev, sign out, and rerun adb devices.

xcodebuild failed with code 65

WebDriverAgent signing failed. Configure a Team and Bundle ID in Xcode.

RemoteXPC tunnel failed

Use USB for iOS 18+, run XCUITest tunnel-creation, and check port permissions.

Appium ECONNREFUSED 4723

Open EchoBench logs for the Appium startup error and check Java, drivers, and port 4723.

Run from source

Only source builds require these tools directly.

Requirements

  • Node.js 22.12+
  • JDK 17
  • Android SDK Platform-Tools
  • scrcpy 3.2 for command-line diagnostics

Build

npm ci npm run typecheck npm test npm run desktop:build
Restart after changing environment variables

Apps launched from Explorer, Finder, or a Linux desktop session do not inherit newly configured terminal variables. Fully quit and restart EchoBench.
